# ImageConv

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

PNG・JPG・WEBP・AVIF形式を相互変換できる軽量ブラウザ拡張機能です。変換はすべてローカルで完結し、データが外部に送信されることはありません。

> Chromium系ブラウザ対応 · Manifest V3 · トラッキングなし · すべてブラウザ内で処理

---

## ImageConvの特長

ほとんどの画像変換ツールは、ファイルをリモートサーバーにアップロードする必要があります。ImageConvはCanvas APIを使用してブラウザ内ですべて完結するため、画像データがマシンの外に出ることはありません。

| 特長 | 詳細 |
|-----------|--------|
| 🔒 **プライバシー最優先** | すべての処理はブラウザのメモリ内で実行されます。アップロードもトラッキングもありません。外部への通信は任意のライセンス検証のみです。 |
| ⚡ **高速変換** | 5MB以下の画像は500ms以内に変換完了。サーバーとの往復待ちが不要です。 |
| 🎯 **依存なし** | バニラJavaScriptとネイティブChrome APIのみで構築。フレームワーク不使用、無駄なコードなし。 |
| 🌍 **6言語対応** | ブラウザの言語設定を自動検出します（英語・スペイン語・ドイツ語・日本語・フランス語・中国語）。 |
| 📋 **コピー＆保存** | 画像を右クリックしてファイルとして保存するか、クリップボードに直接コピーできます。 |
| 📁 **ドラッグ＆ドロップ** | ローカル画像をポップアップにドロップしてすばやく変換できます。 |
| 🖼️ **一括エクスポート** | ページに読み込み済みの画像を一覧表示し、必要なものを選んでまとめて書き出せます。 |

## インストール

### ソースから（開発者モード）

1. ブラウザの拡張機能ページを開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. **デベロッパーモード**を有効にします（右上のトグル）
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`pic-convert`フォルダを選択します
4. ツールバーに✨ ImageConvアイコンが表示されます

## 使い方

### 右クリック変換

1. Webページ上の任意の画像を右クリックします
2. コンテキストメニューから**ImageConv**を選択します
3. **名前を付けて保存**（PNG/JPG/WEBP/AVIF）または**PNGとしてコピー**を選択します
4. 完了 — ファイルが即座にダウンロードされるか、画像がPNGとしてクリップボードにコピーされます

### ドラッグ＆ドロップ／貼り付け（無料）

1. ツールバーのImageConvアイコンをクリックしてポップアップを開きます
2. ローカル画像ファイルをドロップゾーンにドラッグするか、Ctrl+V で貼り付けます
3. 変換先フォーマットを選択します
4. 変換されたファイルが自動的にダウンロードされます

1枚の画像は常に無料です。無料版で複数ファイルをドロップした場合、最初の5枚のみ変換されます。Pro ライセンスで1回あたりの制限が解除されます。一括プリセット、ファイル名テンプレート、ZIP納品はWebの一括エクスポートページでのみ利用でき、ポップアップのドラッグ＆ドロップでは利用できません。

### Web ページ画像の一括エクスポート（無料5枚、Pro 100枚）

1. 対象の画像があるページを開きます（画像が読み込まれている必要があります）
2. ImageConv アイコンをクリックし、**このページの画像を一括エクスポート**を選択
3. 新しいタブに検出された画像が大きい順に一覧表示されるので、必要なものをチェック
4. **オプション**をクリックして形式・品質・サイズを設定します。編集は誰でも可能で、Pro ではさらにプリセットの適用・保存、ファイル名テンプレートの編集、納品方法で**ZIPにまとめる**を選択できます
5. **選択した画像をエクスポート**をクリックします（ZIP納品がオンのときボタンは**ZIPを書き出す**に変わります）

個別ファイルはファイル名テンプレートに従って `ImageConv/` にダウンロードされます。ZIP実行では `ImageConv/<host>-YYYYMMDD-HHmm.zip` を1つダウンロードします。梱包に失敗した場合やアーカイブが4GBを超える場合、完了済みの画像は個別に保存されます。

100 px 未満の画像（アイコン、アバター、トラッキングピクセル）は初期状態で非表示です。ツールバーで絞り込みを変更できます。無料版は1回につき最大5枚、Pro は最大100枚です。

### 品質設定

ポップアップを開いて、スライダーでJPG・WEBP・AVIFの出力品質を調整できます。PNGは常にロスレスです。設定は自動的に保存されます。

### サイズ変更

ポップアップの「サイズ変更」セクションで、倍率（5%〜200%）またはピクセル指定のリサイズが可能です。片方を空欄にすると自動的に比率を維持します。この設定はドラッグ＆ドロップ変換と右クリック変換の両方に適用され、デフォルトは元のサイズです。

### HEIC/HEIF（iPhone写真）

`.heic` / `.heif` ファイルをポップアップにドロップまたは貼り付けるか、ページ上に表示されているHEIC画像を右クリックすると、PNG/JPG/WEBPとして保存できます。デコードはWASMにより完全にローカルで行われ、アップロードは一切ありません。HEIC入力はすべてのプランで無料です。

```
ImageConv
├── PNGとして保存（ロスレス）
├── JPGとして保存（高品質）
├── WEBPとして保存（コンパクト）
├── AVIFとして保存（最高圧縮）
```

**名前を付けて保存**メニューと**PNGとしてコピー**メニューは、リンク内の画像を含め、画像を右クリックした場合にのみ表示されます。画像ファイルへの単なるリンクではメニューは表示されません。クリップボード出力はPNGのみです。

## プライバシー

ImageConvはプライバシーを核となる原則として構築されています：

- ✅ **データアップロードなし** — 画像処理はすべてブラウザのメモリ内で実行されます
- ✅ **アナリティクスなし** — トラッキングもテレメトリもありません。外部通信は、ライセンス認証時およびキャッシュされた 2 時間チェックが切れたときのライセンス検証（ライセンスキー + ランダムなインストール識別子）のみで、画像データが送信されることはありません
- ✅ **Cookie不使用** — ブラウザCookieの読み書きは行いません
- ✅ **閲覧履歴不参照** — ブラウザデータへのアクセスは行いません
- ✅ **一時メモリのみ使用** — 画像は変換中にメモリに存在し、変換後すぐに破棄されます
- ✅ **最小限の権限** — 各機能に必要なものだけを要求します：`contextMenus`、`downloads`、`offscreen`、`storage`、`scripting`、`clipboardWrite`、およびクリックした画像の取得とページの画像スキャンのための `<all_urls>`

## 動作の仕組み

```
画像を右クリック
       ↓
Service Workerが画像blobを取得（クロスオリジン対応）
       ↓
Offscreen Document（Canvasアクセス可能な非表示DOM）にblobを送信
       ↓
Canvasがネイティブ解像度で画像を描画
       ↓
指定品質でターゲットフォーマットとしてエクスポート
       ↓
data URLを返却 → ダウンロードまたはクリップボードコピーを実行
       ↓
すべてのリソース（blob、canvas、画像要素）を破棄
```

> **Offscreenが必要な理由** ChromeのManifest V3ではService Workerとしてバックグラウンドが実行され、DOMアクセスがありません。Canvas APIにはDOMが必要なため、ChromeのOffscreen APIを使用して画像処理用の非表示ドキュメントを作成しています。

## エクスポート品質のデフォルト値

| フォーマット | 品質 | 備考 |
|--------|---------|-------|
| PNG | ロスレス | 品質設定なし — 常に最高品質と透明度を保持 |
| JPG | 92 | 高品質、サイズと鮮明さのバランスに優れる |
| WEBP | 90 | モダンフォーマット、同等品質でJPGより約25〜35%小さい |
| AVIF | 70 | 次世代フォーマット、WEBPより約20〜30%小さい、Web配信に最適 |

すべての品質値はポップアップ内のスライダーで調整可能です（範囲：10〜100）。

> ℹ️ AVIFは内蔵WASMエンコーダによって出力されます（ChromiumのCanvasはネイティブにAVIFエンコードに対応していません）。超大きな画像（2500万ピクセル超）は自動的にWEBPにフォールバックし、通知が表示されます。

## 著作権に関する免責事項

この拡張機能は、ユーザーの個人的なオフライン処理のためのローカル画像フォーマット変換機能のみを提供します。Webページ上のすべての画像、写真、グラフィックリソースは、オリジナルの著作権者に帰属します。ユーザーは変換した画像を商業複製、無断配布、二次創作その他の著作権侵害行為に使用してはなりません。不適切な使用により生じたすべての法的責任は、ユーザーが単独で負うものとします。

## クロスオリジン画像に関する注意

クロスオリジン画像取得機能は、ローカルフォーマット変換のための画像リソース取得にのみ使用されます。この機能を使用してWebサイトの画像リソースを大量にクロールすることは禁止されており、Webサイトのアクセサリー規則に違反する可能性があります。
