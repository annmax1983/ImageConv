# ImageConv

[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，可在本地将图片转换为 PNG、JPG、WEBP 和 AVIF 格式 —— 本地处理，无数据上传。

> 基于 Chromium · Manifest V3 · 无追踪 · 100% 浏览器内处理

---

## 为什么选择 ImageConv？

大多数图片转换工具需要将文件上传到远程服务器。ImageConv 使用 Canvas API 在浏览器内完成所有处理 —— 数据永远不会离开你的设备。

| 优势 | 说明 |
|------|------|
| 🔒 **隐私优先** | 所有处理在浏览器内存中完成，无服务器、无上传、无追踪 |
| ⚡ **即时转换** | ≤5MB 图片转换时间低于 500ms，无需等待服务器往返 |
| 🎯 **零依赖** | 使用原生 JavaScript 和 Chrome API 构建，无框架、无冗余 |
| 🌍 **6 种语言** | 自动检测浏览器语言 —— 英文、西班牙文、德文、日文、法文、中文 |
| 📋 **复制与保存** | 右键图片可保存为文件或直接复制到剪贴板 |
| 📁 **拖拽转换** | 将本地图片拖放到弹窗即可快速转换 |
| 🖼️ **批量导出** | 列出网页上已加载的全部图片，勾选需要的，一次性导出 |

## 安装

### 从源码安装（开发者模式）

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 启用**开发者模式**（右上角开关）
3. 点击**加载已解压的扩展程序**，选择 `pic-convert` 文件夹
4. 工具栏将出现 ✨ ImageConv 图标

## 使用方法

### 右键转换

1. 在网页上右键点击任意图片
2. 从上下文菜单中选择 **ImageConv**
3. 选择**另存为**或**复制为**
4. 选择格式：PNG、JPG、WEBP 或 AVIF
5. 完成 —— 文件立即下载，或图片已复制到剪贴板

### 拖拽转换（Premium）

> ⚠️ 拖拽转换是付费功能，需要许可证密钥。

1. 点击工具栏中的 ImageConv 图标打开弹窗
2. 点击右上角的 🔑 按钮，输入你的许可证密钥
3. 激活成功后，将本地图片文件拖放到拖拽区域
4. 选择目标格式
5. 转换后的文件自动下载

你可以在 [annmax1983.com](https://www.annmax1983.com/checkout.html?plugin=imageconv) 购买许可证密钥。

### 批量导出本页图片（Premium）

> ⚠️ 批量导出是付费功能，需要许可证密钥。

1. 打开包含目标图片的网页（图片需已加载完成）
2. 点击工具栏 ImageConv 图标，再点击**导出本页所有图片**
3. 新标签页会按从大到小列出页面上的全部图片，勾选需要的
4. 选择输出格式，点击**导出所选**
5. 每张图片在本地转换并下载到 `ImageConv/` 目录

默认隐藏小于 100px 的图片（图标、头像、埋点像素），可在工具栏调整筛选；单次最多导出 100 张。

### 质量设置

打开弹窗，使用滑块调整 JPG、WEBP 和 AVIF 的导出质量。PNG 始终无损。设置自动保存。

### 调整尺寸

弹窗中的"调整尺寸"区域支持按百分比缩放（5%–200%）或指定像素宽高。留空一边可自动等比。该设置同时作用于拖拽转换和右键转换，默认保持原始尺寸。

### HEIC/HEIF（iPhone 照片）

将 `.heic` / `.heif` 文件拖入弹窗（或直接转换网页上的 HEIC 图片链接），即可转为 PNG/JPG/WEBP。解码完全在本地通过 WASM 完成，无任何上传。

## 隐私

ImageConv 以隐私为核心原则：

- ✅ **无数据上传** —— 所有图片处理在浏览器内存中完成
- ✅ **无分析** —— 无追踪、无遥测。唯一的对外请求是许可证校验（许可证密钥 + 设备指纹），仅在激活时或 24 小时缓存校验到期时发起，图片数据绝不外传
- ✅ **无 Cookie** —— 不读取或写入浏览器 Cookie
- ✅ **无浏览历史** —— 不访问浏览数据
- ✅ **仅临时内存** —— 图片在转换期间存在于内存中，完成后立即销毁
- ✅ **最小权限** —— 仅请求各功能所需权限：`contextMenus`、`downloads`、`offscreen`、`storage`、`scripting`、`clipboardWrite`，以及用于获取右键图片、扫描页面导出图片的 `<all_urls>`

## 工作原理

```
右键点击图片
       ↓
Service Worker 获取图片 Blob（跨域处理）
       ↓
将 Blob 发送到离屏文档（具有 Canvas 访问权限的隐藏 DOM）
       ↓
Canvas 以原始分辨率绘制图片
       ↓
以指定质量导出为目标格式
       ↓
返回数据 URL → 触发下载或复制到剪贴板
       ↓
销毁所有临时资源（Blob、Canvas、图片元素）
```

> **为什么使用离屏？** Chrome 的 Manifest V3 将后台作为 Service Worker 运行，没有 DOM 访问权限。Canvas API 需要 DOM，因此我们使用 Chrome 的 Offscreen API 创建隐藏文档进行图片处理。

## 导出质量默认值

| 格式 | 质量 | 说明 |
|------|------|------|
| PNG | 无损 | 无质量设置 —— 始终保持完整质量和透明度 |
| JPG | 92 | 高质量，大小和清晰度的良好平衡 |
| WEBP | 90 | 现代格式，同等质量下比 JPG 小约 25-35% |
| AVIF | 70 | 下一代格式，比 WEBP 小约 20-30%，最适合 Web 传输 |

所有质量值均可通过弹窗滑块调整（范围：10–100）。

> ℹ️ AVIF 通过内置 WASM 编码器输出（Chromium 的 Canvas 原生不支持 AVIF 编码）。超大图片（超过 2500 万像素）会自动改用 WEBP 输出并提示。
