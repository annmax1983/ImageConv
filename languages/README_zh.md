# ImageConv

[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，可在本地将图片转换为 PNG、JPG、WEBP 和 AVIF 格式 —— 本地处理，无数据上传。

> 基于 Chromium · Manifest V3 · 无追踪 · 100% 浏览器内处理

---

## 为什么选择 ImageConv？

大多数图片转换工具需要将文件上传到远程服务器。ImageConv 使用 Canvas API 在浏览器内完成所有处理 —— 图片数据永远不会离开你的设备。

| 优势 | 说明 |
|------|------|
| 🔒 **隐私优先** | 所有处理在浏览器内存中完成，无上传、无追踪；唯一的对外请求是可选的授权验证 |
| ⚡ **即时转换** | ≤5MB 图片转换时间低于 500ms，无需等待服务器往返 |
| 🎯 **零依赖** | 使用原生 JavaScript 和 Chrome API 构建，无框架、无冗余 |
| 🌍 **6 种语言** | 自动检测浏览器语言 —— 英文、西班牙文、德文、日文、法文、中文 |
| 📋 **复制与保存** | 右键图片可保存为文件或直接复制到剪贴板 |
| 📁 **拖拽转换** | 将本地图片拖放到弹窗即可快速转换 |
| 🖼️ **批量导出** | 列出网页上已加载的全部图片，勾选需要的，一次性导出 |

## 使用方法

### 右键转换

1. 在网页上右键点击任意图片
2. 从上下文菜单中选择 **ImageConv**
3. 选择**另存为**（PNG/JPG/WEBP/AVIF）或**复制为 PNG**
4. 完成 —— 文件立即下载，或图片以 PNG 格式复制到剪贴板

### 拖拽 / 粘贴转换（免费）

1. 点击工具栏中的 ImageConv 图标打开弹窗
2. 将本地图片文件拖放到拖拽区域，或按 Ctrl+V 粘贴
3. 选择目标格式
4. 转换后的文件自动下载

单张图片始终免费。免费版一次拖入多张时只转换前 5 张；Pro 许可证取消该限制。批量预设、文件命名模板和 ZIP 交付只在网页批量页提供，不适用于弹窗拖拽。

### 批量导出本页图片（免费 5 张，Pro 100 张）

1. 打开包含目标图片的网页（图片需已加载完成）
2. 点击工具栏 ImageConv 图标，再点击**批量导出本页图片**
3. 新标签页会按从大到小列出页面上的全部图片，勾选需要的
4. 点击**选项**设置格式、质量和尺寸。免费版即可修改；Pro 还可以套用或保存预设、编辑文件命名模板，并在「保存方式」中选择**打包为 ZIP**
5. 点击**导出所选**（开启 ZIP 交付后按钮变为**导出 ZIP**）

逐个文件会按命名模板下载到 `ImageConv/`。ZIP 导出会下载一个 `ImageConv/<host>-YYYYMMDD-HHmm.zip`；打包失败或超过 4GB 时，已完成的图片会改为逐张保存。

默认隐藏小于 100px 的图片（图标、头像、埋点像素），可在工具栏调整筛选；免费版单次最多导出 5 张，Pro 最多 100 张。

### 质量设置

打开弹窗，使用滑块调整 JPG、WEBP 和 AVIF 的导出质量。PNG 始终无损。设置自动保存。

### 调整尺寸

弹窗中的"调整尺寸"区域支持按百分比缩放（5%–200%）或指定像素宽高。留空一边可自动等比。该设置同时作用于拖拽转换和右键转换，默认保持原始尺寸。

### HEIC/HEIF（iPhone 照片）

将 `.heic` / `.heif` 文件拖入或粘贴到弹窗，或右键网页上显示的 HEIC 图片，即可转为 PNG/JPG/WEBP。解码完全在本地通过 WASM 完成，无任何上传。所有版本的 HEIC 输入均免费。

## 右键菜单结构

- 另存为 PNG（无损）
- 另存为 JPG（高质量）
- 另存为 WEBP（紧凑）
- 另存为 AVIF（最佳压缩）
- 复制为 PNG（无损）

**另存为**和**复制为 PNG**菜单仅在右键点击图片时显示，包括链接内的图片；普通图片文件链接不会显示菜单。剪贴板输出仅支持 PNG。

## 隐私

ImageConv 以隐私为核心原则：

- ✅ **无数据上传** —— 所有图片处理在浏览器内存中完成
- ✅ **无分析** —— 无追踪、无遥测。唯一的对外请求是许可证校验（许可证密钥 + 随机安装标识），仅在激活时或 2 小时缓存校验到期时发起，图片数据绝不外传
- ✅ **无 Cookie** —— 不读取或写入浏览器 Cookie
- ✅ **无浏览历史** —— 不访问浏览数据
- ✅ **仅临时内存** —— 图片在转换期间存在于内存中，完成后立即销毁
- ✅ **最小权限** —— 仅请求各功能所需权限：`contextMenus`、`downloads`、`offscreen`、`storage`、`scripting`、`clipboardWrite`，以及用于获取右键图片、扫描页面导出图片的 `<all_urls>`

## 工作原理

1. 右键一张图片，选择目标格式。
2. 浏览器负责取图并解码，跨域图片同样处理。
3. 按原始分辨率重绘后，编码为你设定的 PNG / JPG / WEBP / AVIF 格式与质量。
4. 结果直接下载或送入剪贴板，所有临时资源随即释放。

---

## 导出质量默认值

| 格式 | 质量 | 说明 |
|------|------|------|
| PNG | 无损 | 无质量设置 —— 始终保持完整质量和透明度 |
| JPG | 92 | 高质量，大小和清晰度的良好平衡 |
| WEBP | 90 | 现代格式，同等质量下比 JPG 小约 25-35% |
| AVIF | 70 | 下一代格式，比 WEBP 小约 20-30%，最适合 Web 传输 |

所有质量值均可通过弹窗滑块调整（范围：10–100）。

> ℹ️ AVIF 通过内置 WASM 编码器输出（Chromium 的 Canvas 原生不支持 AVIF 编码）。超大图片（超过 2500 万像素）会自动改用 WEBP 输出并提示。
