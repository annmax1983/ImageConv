ImageConv Privacy Policy

All conversion happens inside your browser and your converted files are never uploaded. The extension contacts the network in two cases only: it fetches the original image from the site you right-clicked (or from the page's own image URLs during batch export), and it validates an optional Premium licence. Those image requests go straight to the source website, which may see your IP address and request metadata. No analytics, no account.

01What ImageConv Does

ImageConv is a browser extension that converts images between PNG, JPG, WEBP, and AVIF formats. All conversion is performed locally in your browser using the Canvas API.

02Data Collection

ImageConv does not collect any personal data, including but not limited to:

  • Images or image content
  • Browsing history
  • Cookies or tracking identifiers
  • IP addresses or location data
  • Usage analytics or telemetry

03Data Transmission

ImageConv does not upload image data or browsing data to us. It fetches the source image directly from the website you act on, and contacts api.annmax1983.com only for optional Premium licence checks. If you never activate a licence, the licence server is never contacted. Source websites may log the image request as they would any normal page request.

04Data Storage

ImageConv stores the following data locally on your device using chrome.storage.local:

  • Settings — your quality preferences and toggle states
  • Usage count — a simple counter of total conversions (not linked to any identity)
  • Install ID — a random identifier generated for this installation, used to count license activations.
  • License data — license key and activation status, stored locally. If the server cannot be reached, the cached license keeps working until the next successful check

Local data stays on your device except for the optional licence fields described under Third-Party Services; uninstalling deletes the local copy.

05Permissions

ImageConv requests the minimum permissions necessary:

  • contextMenus — to add the right-click "Save as / Copy as" menu
  • downloads — to save converted images to your computer
  • offscreen — to run Canvas-based image conversion in a hidden document
  • storage — to remember your settings locally
  • scripting — to show status notifications on the page, and to scan a page for its images when you use batch export
  • clipboardWrite — to copy converted images to your clipboard

Host permission <all_urls> is required to fetch images from any website when you right-click to convert, and to read the images already loaded on a page when you use batch export. Apart from that, ImageConv does not access page content.

06Third-Party Services

License Verification (Premium Features): If you activate a premium license, ImageConv contacts our license server (api.annmax1983.com) directly; Creem only handles the payment. The request includes: license key, a random install identifier, plugin identifier, and browser metadata (version, language, timezone). ImageConv does not connect to any other third-party servers, analytics, or tracking services. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

07Children's Privacy

ImageConv does not knowingly collect any data from children or any other users.

08Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them.

09Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.
